# Changelog

Semua perubahan penting pada Pedoman TA IF ITERA.

## [1.0.0] - 2025-06-24

### Added

- Pedoman TA lengkap (8 Bab + 8 Lampiran) dalam format markdown
- Website pedoman TA dengan sidebar navigasi dan dark/light mode
- Halaman sosialisasi (slide presentation) berbasis web
- Changelog untuk tracking perubahan

### Changed

- Sinkronisasi 34 poin dengan PDF Sosialisasi:
  - Batas waktu semua bentuk TA: 2 → **3 semester**
  - Capstone: jumlah anggota tetap **3 orang**
  - Artikel: standar publikasi **SINTA 1–4** (bukan SINTA 5)
  - HKI/Paten: jumlah mahasiswa **2–3** (bukan 3–4), wajib demo
  - TTG: TKT minimum **Level 6** (bukan Level 4)
  - Kehadiran sempro lain: 5 → **2 kali**
  - Durasi presentasi sempro: **10 menit**, sidang: **10+5 menit**
  - Tanya jawab sidang: **50 menit**
  - Buku: syarat **PRISMA**
  - Checklist sidang: tambah **Surat Izin Penelitian**

### Fixed

- Formatting markdown dari konversi Word (anchor tags, spacing, tabel)
- Struktur heading hierarkis (#/##/###/####) untuk semua bab & lampiran
